## 🎯 Interview Talking Points

### "How is your app deployed?"
> "CityPulse uses a modern cloud-native architecture: the React frontend is deployed on Vercel for global availability, the FastAPI backend runs in a Docker container on Render with PostgreSQL on Neon. All services are free tier with no credit card required. The backend auto-deploys when I push to GitHub, and the frontend uses environment variables to connect to the backend API."

### "Why these technologies?"
> "I chose these platforms specifically to demonstrate full-stack capabilities in a cost-effective way. Docker shows containerization knowledge, PostgreSQL shows database optimization, Render shows deployment experience, and Neon shows serverless database configuration. The architecture uses industry best practices: secrets in environment variables, connection pooling for database efficiency, CORS for API security, and health checks for monitoring."

### "What about the data?"
> "The app uses a normalized PostgreSQL schema with a three-level hierarchy: cities, areas, and indicators. I implemented proper foreign key relationships and wrote an ETL pipeline (seed.py) that populates the database with 26 neighborhoods across 3 cities. The backend uses SQLAlchemy ORM with optimized queries and connection pooling for serverless performance."
