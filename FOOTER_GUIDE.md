## 🔧 Customization Options

If you want to change anything in the future:

### Change GitHub Link
In `App.js`, find:
```javascript
href="https://github.com/frankTheCodeBoy"
```
Replace `frankTheCodeBoy` with your new GitHub username

### Change Your Name
In `App.js`, find:
```javascript
Francis Olum
```
Replace with your preferred name/nickname

### Change Copyright Years
In `App.js`, find:
```javascript
CityPulse © 2024-2026
```
Change years as needed

### Change Skills Listed
In `App.js`, find:
```javascript
Data Engineering | Full-Stack Development | Cloud Deployment
```
Change to your skills

### Change Heart Color
Currently it's:
- Light mode: Orange (#ff8f00)
- Dark mode: Pink (#ff6b9d)

Can be customized in the theme
