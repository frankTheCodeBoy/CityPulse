# CityPulse 🌆 — Urban Intelligence Platform

## Vision
CityPulse is a flagship Analytics Engineering product designed to help businesses, planners, and decision-makers understand how cities grow, move, and evolve through data-driven urban intelligence.

## Scope
- MVP: Nairobi (CBD, Westlands, Kilimani, Karen, Ruiru)
- Proprietary outputs: Urban Health Score, Opportunity Score, Growth Index, Infrastructure Index

## Tech Stack
- Backend: FastAPI
- Database: PostgreSQL + PostGIS
- ETL: Python pipelines
- Frontend: React + Plotly
- Mapping: Leaflet / Mapbox
- AI Layer: LLM-powered narrative summaries
